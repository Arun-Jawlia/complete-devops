# Introduction to Cloud

## What is Cloud?

Cloud Computing is the delivery of computing services over the Internet instead of using your own physical hardware.

Instead of buying and maintaining servers, storage, and networking devices, you can rent these resources from a cloud provider and pay only for what you use.

### Cloud Services Include

* Virtual Machines
* Storage
* Databases
* Networking
* Security
* AI & Machine Learning
* Monitoring
* Serverless Computing

### Why Use Cloud?

* No need to buy physical servers
* Pay only for what you use
* Easily scale resources
* High availability
* Faster deployment
* Global accessibility

---

# Different Types of Services

Cloud services are mainly divided into three categories.

## 1. IaaS (Infrastructure as a Service)

IaaS provides basic infrastructure such as servers, storage, networking, and virtual machines.

The cloud provider manages the hardware, while you manage the operating system, applications, and data.

### Examples

* Amazon EC2
* Azure Virtual Machines
* Google Compute Engine

### Use Cases

* Hosting applications
* Creating virtual machines
* Development and testing
* Disaster recovery

---

## 2. PaaS (Platform as a Service)

PaaS provides a complete platform to build, deploy, and manage applications without worrying about infrastructure.

The provider manages servers, operating systems, runtime, and middleware.

You only focus on writing application code.

### Examples

* AWS Elastic Beanstalk
* Google App Engine
* Azure App Service

### Use Cases

* Web application development
* API development
* Mobile backend services

---

## 3. SaaS (Software as a Service)

SaaS provides ready-to-use software over the Internet.

Users simply access the software through a web browser without installing or maintaining it.

### Examples

* Gmail
* Microsoft 365
* Google Docs
* Zoom
* Slack

### Use Cases

* Email
* Collaboration
* Video meetings
* Office applications

---

# IaaS vs PaaS vs SaaS

| Feature          | IaaS       | PaaS       | SaaS         |
| ---------------- | ---------- | ---------- | ------------ |
| Infrastructure   | ✅          | Managed    | Managed      |
| Operating System | You Manage | Managed    | Managed      |
| Runtime          | You Manage | Managed    | Managed      |
| Application      | You Build  | You Build  | Ready to Use |
| End User         | Developers | Developers | Everyone     |

# Different Types of Cloud

## 1. Public Cloud

A public cloud is owned and managed by a third-party cloud provider.

Resources are shared among multiple customers.

### Examples

* AWS
* Azure
* GCP

### Advantages

* Low cost
* Easy to scale
* No infrastructure management

---

## 2. Private Cloud

A private cloud is dedicated to a single organization.

Infrastructure is not shared with other users.

### Advantages

* Higher security
* More control
* Better compliance

### Best For

* Banks
* Government organizations
* Healthcare

---

## 3. Hybrid Cloud

A hybrid cloud combines both public and private clouds.

Organizations keep sensitive data in a private cloud while using the public cloud for scalable workloads.

### Advantages

* Better flexibility
* Improved security
* Cost optimization

### Example

Store customer data in a private cloud while hosting the web application on AWS.

# Service Providers

## 1. Amazon Web Services (AWS)

AWS is the world's largest cloud platform.

Popular Services:

* EC2
* S3
* RDS
* Lambda
* VPC
* EKS

---

## 2. Microsoft Azure

Azure is Microsoft's cloud platform and is widely used by enterprises.

Popular Services:

* Virtual Machines
* Azure Storage
* Azure SQL Database
* Azure Kubernetes Service (AKS)
* Azure Functions

---

## 3. Google Cloud Platform (GCP)

GCP is Google's cloud platform, known for data analytics, AI, and Kubernetes.

Popular Services:

* Compute Engine
* Cloud Storage
* BigQuery
* Google Kubernetes Engine (GKE)
* Cloud Functions

---

# Summary

* **Cloud Computing** provides IT resources over the Internet.
* **IaaS** provides infrastructure like servers and storage.
* **PaaS** provides a platform to build and deploy applications.
* **SaaS** provides ready-to-use software.
* **Public Cloud** is shared and managed by cloud providers.
* **Private Cloud** is dedicated to one organization.
* **Hybrid Cloud** combines public and private clouds.
* The three major cloud providers are **AWS**, **Microsoft Azure**, and **Google Cloud Platform (GCP)**.
